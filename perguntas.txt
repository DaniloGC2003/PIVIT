- Sugestão para detecção de botão pressionado nas ESPs: usar um relé que inverte o sinal de alguma porta GPIO a cada vez que é apertado. Com isso, quando a ESP receber a mensagem para ativar o cronômetro, será lido o sinal dessa porta (0 ou 1). Quando houver inversão desse sinal, sabemos que o botão foi pressionado. Esse método elimina a verificação de botão pressionado dentro do código. Tal verificação é menos eficiente pois a ESP exige um tempo de delay a cada ciclo. É possível que o botão seja pressionado e solto durante esse intervalo de delay, de forma que o pressionamento do botão não seja detectado pelo programa.
